## 🚀 Projetos em Destaque

### 🔊 [Sistema de Monitoramento com Análise de Áudio](https://github.com/Shayder007/Projeto-de-monitoramento)
> **Tecnologias:** `C` · `Raspberry Pi Pico W` · `BitDogLab` · `CMake` · `Processamento de Sinais` · `IoT`

Sistema embarcado de monitoramento para ambientes domésticos, voltado à segurança de idosos, crianças e pessoas com deficiência. Utiliza microfones e DMA (Direct Memory Access) para captura eficiente de áudio em tempo real, com algoritmos de detecção de eventos críticos como quedas e gritos de socorro por análise de frequência e amplitude — sem ativar falsos positivos com sons cotidianos.

**Diferenciais técnicos:**
- Captura de áudio com DMA para alta performance em microcontrolador
- Controle de matriz de LEDs NeoPixel via protocolo PIO customizado (WS2812B)
- Implementação de análise espectral em hardware com recursos limitados
- Integração de IoT para envio de alertas remotos

**Impacto:** Demonstra capacidade de trabalhar com hardware de baixo nível, programação embarcada em C e integração de sistemas físicos com software — uma combinação rara em candidatos iniciantes.
